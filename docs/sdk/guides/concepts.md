# 核心概念

## 设备角色

| 角色 | 功能 | Python 入口 |
|---|---|---|
| 从爪 follower / slave | 电机驱动，接收目标开口 | `Gripper` |
| 主爪 leader / master | 采集手动开口和 IMU | `advanced.LeaderGripper` |
| XC 腕相机 | 图像采集 | `advanced.Camera` |

固件序列号以 `s` 结尾表示从爪，以 `m` 结尾表示主爪。
`left/right` 是侧别，与主从角色独立。左右从爪都使用 slave 固件。

## 控制会话

`Gripper` 管理一台从爪的连接与控制生命周期：

```text
连接 → start / 首次运动 → 持续控制 → disable → 空闲 → close
```

连接是被动的。`start()` 使能并保持当前点，首次运动也可自动启动。
模式切换复用同一后台运行时。活动会话退出时请求失能。
同一设备应由一个应用控制；不要同时运行控制脚本、GUI 或 OTA。

## 坐标与单位

| 量 | 单位 | 说明 |
|---|---|---|
| 目标 / 反馈开口 | `[0,1]` | 按设备标定行程归一化；不是毫米或弧度 |
| 位置参考速度 | rad/s | 电机参考的变化速率上限 |
| 扭矩预算 / 反馈 | N·m | 电机轴侧量；不是爪尖夹持力 N |
| 电机温度 | ℃ | 电机上报温度 |
| 观测年龄 | ms | 用于判断反馈是否新鲜 |

`info.reversed` 描述电机安装方向。归一化目标始终是 0 闭合、1 张开，
无需由应用反转；原始速度和阻抗前馈扭矩保留电机坐标符号。

## 目标、到位与接触

`set_position` 提交目标后，SDK 持续刷新最新值。新的目标替换旧目标，不进入队列。
物体阻挡目标时，夹爪继续在预算内朝目标施力；位置误差可以持续存在。

`reached` 表示位置与速度满足到位条件。`contact` 表示抓取模式推断接触。
两者都不表示经过独立检测的稳定夹持。位置模式不自动产生接触完成结果。

## SDK 与固件

SDK 负责目标策略、归一化、观测与主机资源；固件负责目标执行、反馈检查、
行程与动态输出约束。位置控制最终使用电机 MIT / MOTION 模式。

SDK 请求预算、固件动态包络和电机限值共同约束输出。请求 0.6 N·m 并不意味着
每个时刻都输出 0.6 N·m；固件因静止时长或温度降额时，实际允许值还会降低。

## 三种频率

| 频率 | 含义 |
|---|---|
| 应用目标频率 | 模型或遥操产生新动作的频率 |
| SDK / 反馈频率 | `update_hz` 配置，支持 20、25、40、50、100 Hz |
| 机械轨迹频率 | 机构实际运动快慢，受幅度、负载、速度和扭矩影响 |

100 Hz 状态流不表示可以准确跟随 100 Hz 机械轨迹。
应用可以低于 SDK 频率更新目标；两次更新之间 SDK 保持最新目标。
